# 営業面談7件から逆算する「まけどりが発信すべきポスト」戦略

> 7件の営業文字起こしから、**見込み客が抱える本音・壁・欲求**を抽出し、 
> 「このポストを見ていたら面談前に自分で壁を乗り越えてくる」状態を作る発信テーマを提案する。

---

| カテゴリ | パターン | 該当者 |
|---------|---------|--------|
| **副業完全初心者** | 教材購入歴ゼロ、情報収集始めたばかり | 川瀬 |
| **他副業で疲弊・失敗済** | 物販・動画編集・アダルトアフィで挫折 | 長崎 |

| **生活費トントン・投資余力なし** | お小遣い制、住宅ローンあり | 川瀬 |

## 2. 成約を阻む5大ボトルネック

|---|-----------|---------|--------|

## 3. 見込み客が「刺さった」キーワード（面談内で反応が良かったもの）

面談中に明確に反応が良かったポイント＝**ポストで先出しすべきネタ**：

1. **「フォロワー300人で30万円」** → 常識破壊のフック
2. **「800インプで50リプ」** → 他市場ではあり得ないエンゲージメント率
3. **「外注月1万・1アカウント30分/日」** → 時間がない人への決め手
4. **「ノートの中身は質を求められない」** → ファンクラブ心理の解説
5. **「93%が2ヶ月で30万」** → 再現性の証明
6. **「ストック型収入」** → 忙しい人への刺さりワード
7. **「300万借金→逆転」** → ノウハウコレクターからの復活ストーリー

## 7. 最重要ポスト3本（今すぐ作るべき）

### ① 「AIスクールに100万払って月収1万だった人が、裏垢始めて2ヶ月で月30万になった話」
- **根拠**: ユウタ・むうの状況がそのまま見込み客の代弁になる
- **フック**: AIスクール経験者の共感 → 裏垢への導線

### ② 「フォロワー300人で月30万売れる市場、知ってる？」
- **根拠**: 全面談で最も反応が良かったデータポイント
- **フック**: 常識破壊 → 「どういうこと？」という好奇心

### ③ 「副業3つ失敗して1000万借金した僕が、月200万安定した方法」
- **根拠**: こっそり・及川の実体験。面談でも共感を生んでいた
- **フック**: 失敗→逆転のストーリーは普遍的に刺さる
